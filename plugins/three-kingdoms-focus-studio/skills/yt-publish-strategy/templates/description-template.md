# 影片說明範本

> **核心原則**：說明同時服務三個對象，各有各的需求——
> ① **機器**（搜尋匹配，只看最前面）② **觀眾**（需要停留與互動）
> ③ **YouTube 審核者**（檢查是否有原創見解）。
>
> 這三個目標不衝突，但必須**分層呈現**，不能混成一段。

---

```markdown
<搜尋匹配句 ×2，中英文各一，纯陳述，不加文學包裝>

60～90 分鐘中國風專注音樂，以古琴、簫與古箏陪你完成一段不被打擾的工作。
```

## 分層說明

### 第 1 層：搜尋匹配句（給機器，必須在最前面）

**這是整份說明最重要的部分。** 官方 141805 明文：搜尋匹配靠
"the title, description, and video content"。

**規則**：

- 放**第一行**，不要有任何引言、emoji 或引導語
- 包含：**時長 + 樂器 + 用途 + 中英文**
- 純陳述句，**不要**文學包裝
- 英文放前面（實測中文標題在英文關鍵字無 10 萬級案例）

**✅ 好的**：

```markdown
90 分鐘中國風專注音樂，古琴、簫與古箏，適合閱讀、學習與深度工作。
90-minute Chinese instrumental focus music with guqin and xiao — for study, reading, writing and deep work.
```

**❌ 壞的**（你現況的問題：開頭全是散文）：

```markdown
有些力量，不在衝鋒時，而在紛亂之中，仍能把眼前的一件事做好。
《案上清明 / Clarity at the Desk》把趙雲的沉著帶進現代辦公室…
```

→ 這段很有文學性，但**一個觀眾會搜的字都沒有**。

### 第 2 層：正文（給觀眾，保留文學性）

這是你的差異化資產，**不要為了 SEO 改寫它**。
望樓筆記靠的就是這類有情緒的文案，單支 249,103 觀看。

### 第 3 層：創作筆記（給審核者，變現保命）🔴

**政策禁止的是 AI 生成內容「沒有加入創作者原創、真實的見解或觀點」**
（官方 1311392 原文）。純器樂頻道沒有旁白，所以必須在文字上讓創作決策可見。

**必須寫出具體的創作決策，不能寫空話。** 判準是：
「看完這段，讀者能知道這支片和上一支在**哪個具體層面**不同。」

| ✅ 有效（具體決策） | ❌ 無效（空話） |
|---|---|
| 「刻意迴避戰場元素，改以現代辦公室的日常張力」 | 「本片是一首優美的中國風音樂」 |
| 「第 3 段起刻意減法，只留簫的長音」 | 「配器精心安排」 |
| 「全曲 7 段結構依情緒曲線分章」 | 「結構完整」 |
| 「視覺由音樂段落結構直接驅動生成」 | 「視覺精美」 |

**自我檢測**：寫不出「這支片和上一支的具體差異」→ 那一支確實是模板，
**先回去重做音樂，不要硬寫**。這段附註的最大價值就在這個自我檢測。

### 第 4 層：章節時間軸

長片能被推薦與被搜尋的前提。必須與**音樂的實際結構**對齊，不是湊出來的。

⚠️ 章節切點同時是 **mid-roll 廣告切點**（官方 6175006 會在「音樂停頓 / 視覺轉場」
處插廣告），排版時要一起想。

### 第 5 層：免責與 hashtag

**免責必留**（兩句都要）：

```
關於作品：本片以<人物>為靈感進行現代情境的藝術化演繹，並非歷史場景還原。
音樂提供氛圍陪伴，不代表醫療或治療效果。
```

**hashtag 規則**（官方 6390658）：

- 每個要嘛是**需求詞**（專注、學習、放鬆、入睡、古琴、鋼琴），
  要嘛是**品牌詞**（三國、趙雲）
- **刪掉**描述製作形式的：`#AI動畫` `#沉浸式動畫` `#數位繪畫` `#通勤動畫` `#電影感`
- ≤ 15 個（超過 60 個官方全部忽略，但中間就已經稀釋相關性）
- **確認沒有黏連**：`#FocusMusic#Shorts` 無法解析成兩個 tag
- **統一繁體**：`#赵云` → `#趙雲`
- 只有**前 3 個**會顯示在標題旁

⚠️ 官方 Non-hashtags 條款：
> "adding ordinary descriptive tags or repetitive sentences in the description is (still) prohibited"

→ **不要堆疊描述性標籤字串。**

### 建議 hashtag 組合

```markdown
#專注音樂 #FocusMusic #學習音樂 #StudyMusic #古琴音樂 #三國
```

或英文為主：

```markdown
#FocusMusic #StudyMusic #ChineseInstrumental #GuqinMusic #AmbientMusic
```

## 標記（Tags）— 說明以外的另一個欄位

> YouTube Studio → Details → **Show more → Tags**。觀眾看不到，與 hashtag 不同欄位、不同規則。

**貼上用**

```
<主目標片語>, <需求詞×3>, <樂器詞×3>, <拼寫變體×1>, <類型詞×1>, <中文需求詞×2>, <品牌詞×1>
```

自檢：

- [ ] **總字元數 ≤ 500**（含逗號；超了會從尾端**無聲截斷**）
- [ ] 沒有填滿 500（5～15 個就夠，填滿只會稀釋相關性）
- [ ] 最重要的在**最前面**（YouTube 依序讀取，截斷也從尾端發生）
- [ ] 每個都是需求詞／樂器詞／拼寫變體／品牌詞
- [ ] 沒有描述製作形式的詞
- [ ] 沒有不相干的熱門關鍵字
- [ ] 頻道層級的「關鍵字 (Keywords)」也設定了（Settings → Channel → Basic info，同樣 500 字元上限，但描述**整個頻道**）

## 常見錯誤速查

| 錯誤 | 後果 | 修法 |
|---|---|---|
| 說明開頭全是散文 | 搜尋完全匹配不到 | 最前面加搜尋匹配句 |
| 沒有創作筆記 | 變現審查風險（政策禁止「無原創見解」） | 加創作筆記段 |
| 15 支說明結構雷同只換名字 | 強化「template」印象 | 每支寫出不同的創作決策 |
| hashtag 描述製作形式 | 相關性被稀釋 | 換成需求詞與樂器名 |
| 把標記欄填滿 500 字元 | 不相干的詞稀釋相關性，且尾端被無聲截斷 | 留 5～15 個，把變體與品牌詞放前面 |
| 把 hashtag 與標記互相複製 | 兩個欄位規則不同，重複不加分 | hashtag 放需求／品牌／樂器詞；標記放拼寫變體與標題塞不下的片語 |
| hashtag 黏連 | tag 無法解析 | 每個 `#` 間加空格 |
| 承諾「無廣告版」 | 無法兌現 | 拿掉，或改說明「專注陪伴、不搶注意力」 |
| 繁簡混用 | 全站風格不一致 | 統一繁體 |
