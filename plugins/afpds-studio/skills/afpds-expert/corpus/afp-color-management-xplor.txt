How important is it to get the exact color?

(cid:137) In most cases, e.g. photographic images, visually          

“pleasing colors” are adequate

(cid:137) In at least one case, corporate logos, we want the colors to be 

exactly correct, unfortunately this is rarely possible with printers 
that use a four-color, CMYK, process

(cid:137) With CMYK printers compromises are required when attempting 

to reproduce specific colors

(cid:137) Check to see if the printer you are considering can reproduce 

the colors you require!

ICC Profiles

(cid:137) File format defined by the International Color Consortium, ICC
(cid:137) Describes the color characteristics of a particular device: digital 

camera, scanner, monitor, printer

(cid:137) Used to intelligently-transform, device-unique, color information 

between devices

(cid:137) For printers color characteristics change with type of paper used, 

e.g. coated and uncoated; worst case: separate ICC profile 
required for each paper type

(cid:137) ICC profile is also called a Color Space, and in Photoshop it can 
be the Working Space which identifies the profile used for editing 

(cid:137) ICC profiles are provided by the device vendor and can also be 

created by the user using special hardware/software

ICC Profile 3D Colorspace Comparisons

(cid:137) ICC profiles describe the color gamut supported by the device
(cid:137) A three-dimensional representation allows exact comparison of 

the color capabilities of two devices

(cid:137) The ICCView website builds a 3D model comparing any two ICC 
profiles and is available at: http://www.iccview.de/index_eng.htm

(cid:137) Model depicts CIE L*a*b* colorspace

(cid:131) L* = Lightness
(cid:131) a* = green-magenta axis
(cid:131) b* = yellow-blue axis

CIE = International Commission on Illumination, 
or, Commission Internationale de l'Eclairage

Color Management with ICC Profiles

1. A Color Management System uses the input image’s ICC 
profile to convert its colors to a device-independent format 
called the Profile Connection Space.  

2. Then the target printer’s ICC profile is used to convert the 
device-independent image to the printer-specific format.

Plus: Color objects can print correctly on any device

that supports ICC profiles

Rendering Intents
(cid:137) Specifies color conversion when moving from one color space, 
(ICC profile), to another; i.e. how to handle colors, in an image, 
that cannot be reproduced exactly on a printer or monitor 

(cid:137) Perceptual: 

(cid:131) Preserves visual relationships between colors, 
(cid:131) Compresses image’s gamut to fit within that of target device
(cid:131) Most pleasing for photographic images

(cid:137) Saturation:

(cid:131) Produces vivid colors at expense of accuracy
(cid:131) Most suitable for business graphics
(cid:137) Colorimetric (Relative and Absolute):

(cid:131) Match colors exactly and clip out-of-gamut colors 
(cid:131) Used for logos and proofing 
(cid:131) Relative maps source white to paper white (logos)
(cid:131) Absolute tries to preserve source white in destination (proofing)

Color Management Resources, CMRs

(cid:137) New AFP resource type to implement color management
(cid:137) 5 Types:

(cid:131) Color Conversion (CC): Contains ICC Profile which describes the color 
characteristics of a Data Object, (e.g. TIFF/JPEG), or printer; used to 
convert color data between the two

(cid:131) Tone Transfer Curve (TTC): Specifies grayscale appearance:

(cid:127) Dark
(cid:127) Accutone
(cid:127) Highlight Midtone
(cid:127) Standard

(cid:131) Halftone (HT): Specifies halftone line screen 
(cid:131) Indexed (IX): Extends highlight color support for colorant mixing
(cid:131) Link Color Conversion (LK): Look-up tables that convert colors directly 
from the input color space to the output color space; helps performance

Resource Access Table (RAT)

RAT

(cid:137) When Data Objects and CMRs are installed in resource libraries, 

they are processed using a Resource Access Table (RAT)

(cid:137) Maps a resource name, specified in the application print file, to the 

resource file name and other information needed to process it

(cid:137) Allows resources to be referenced in data stream by their 
inherent, native name, not by a platform-specific file name
(cid:137) RATs are located in same directory as the resources they map
(cid:137) RATs were first introduced in AFP with TrueType/OpenType fonts
(cid:137) There are three types of RATs, each with a hard-coded file name:

(cid:131) Data Object RAT: AFP_DataObjectResource.rat
(cid:131) Color Management Resource RAT: AFP_ColorManagementResource.rat
(cid:131) TrueType/OpenType Font RAT: IBM_DataObjectFont.rat

Specifying Line Screen and Appearance for Monochrome 
Printers that Support the Color Architecture

Application Pagedef

OBJECT CCBIG    OBXNAME CCBIG    OBKEEP PRELOAD OBTYPE OTHER OBID TIFF

OB2CMR ‘106lpi’ OB2XNAME ‘HTgeneric106’ instr
OB2CMR ‘hilitemidtone’ OB2XNAME ‘TCgenerichilmid’ instr;

(cid:137) The command above uses generic CMRs to request a line screening of 106lpi 

and an appearance of highlight midtones.  

(cid:137) Generic CMRs allow a device-independent specification, similar to Infoprint 

Submit, where the actual result may not exactly match the requested value.  For 
example, when a line screen of 106lpi is requested on a 4100-HD3/4 the actual 
line screen generated is 96lpi.

(cid:137) Specific CMRs can be used instead of generic however an error will occur if the 

device cannot provide the requested value.
