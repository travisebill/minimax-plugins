Recommended IPDS Values for Object Container Versions

AFPC-0017-02

Last update: 1/12/2015

This document lists recommendations for values to be returned in the Object Container Version Support self-defining field of the IPDS XOH:OPC reply.

The following table lists recommended values that an IPDS printer should return if it supports the versions listed.

This document is non-normative and can be updated at any time.  The intention, however, is that once officially published (in conjunction with the first edition of the IPDS 
Reference that contains the Object Container Version Support self-defined field), information will only be added , and will never be changed.  Furthermore, the intention is 
that information will likely only be added when requested--this document will not attempt to keep up-to-date on all possible versions of all possible object containers.

To request an update to this document, contact Dennis Carney (Ricoh).
